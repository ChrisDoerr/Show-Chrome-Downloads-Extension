# Show Downloads in Chrome

Chrome sometimes shows the downloads bubble instead of opening the full Downloads page.

I find that annoying, so I made this tiny extension: click its toolbar icon to open `chrome://downloads/`.

Sorry, this extension doesn't add a Ctrl+J shortcut.

## Incognito Mode
In order for the icon also to be present when browsing in incognito mode, open "manage extensions" and click the "details" button for this extension.
There, activate **"Allow in Incognito"**
